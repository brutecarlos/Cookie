Content Licensing Notes — Cookie

Do you need Creative Commons?
- Not necessarily.
- You only need Creative Commons attribution if you use content licensed under a CC license that requires attribution (for example, CC BY).

Safe options:
1. Use only original quotes/artwork you own.
2. Use public-domain content.
3. Use CC-licensed content only if you follow the exact license terms (attribution, share-alike, non-commercial limits, etc.).

For Chrome Web Store review, keep a record of:
- source of each quote/image/icon,
- license type,
- required attribution text,
- URL to source/license.

Recommended for this project:
- Keep `quotes.json` to content you own or public-domain text.
- Keep icons/screenshots as your own original artwork.
- If you include third-party content, add an attribution section in `README.md` and (if needed) in the store listing.

Attribution template:
- "[Asset/Quote name]" by [Author], licensed under [License], source: [URL].
